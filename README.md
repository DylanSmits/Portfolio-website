# Portfolio website — Alfa-college

Een responsive portfolio website gemaakt met HTML, CSS en JavaScript, met een donkerblauwe achtergrond, witte tekst en gele accenten.

## Bestanden
- `index.html` — pagina-inhoud en secties
- `css/style.css` — kleuren, layout, responsive design en componenten
- `js/script.js` — mobiel menu, jaartal en contactformulier
- `images/` — plaats hier screenshots van je eigen projecten

## Openen in VS Code
1. Pak de ZIP uit.
2. Open VS Code.
3. Kies **File → Open Folder** en selecteer de map `portfolio_alfa_college`.
4. Open `index.html` in je browser, of gebruik de VS Code-extensie Live Server en klik op **Go Live**.

## Voor je de website inlevert
1. Vervang `[Jouw naam]` door je eigen naam.
2. Vervang `VUL-HIER-JE-EMAIL-IN` door je eigen e-mailadres in `index.html` en `js/script.js`.
3. Controleer de vaardigheidsniveaus en pas ze eerlijk aan.
4. Controleer dat elke projectbeschrijving overeenkomt met wat je echt hebt gemaakt.
5. Vervang de CSS-projectillustraties door screenshots van je eigen apps. Bewaar screenshots in `images/` en pas de projectkaarten in `index.html` aan.
6. Test alle navigatielinks en het contactformulier.

## Belangrijk over het contactformulier
Omdat deze versie alleen HTML, CSS en JavaScript gebruikt, verstuurt het formulier geen berichten via een server. Na het invullen wordt een `mailto:`-link geopend in het standaard e-mailprogramma van de bezoeker. Voor automatisch versturen vanaf de website is een backend of externe formulierdienst nodig.

## GitHub Pages
Deze website kan als statische website op GitHub Pages worden gepubliceerd. Let op: GitHub Pages ondersteunt geen PHP-backend.
